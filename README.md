# oboeru-blank-map

国名を覚えるための白地図です。
> https://kuansy373.github.io/oboeru-blank-map/

### **使い方**
- 国名を言いながらその国をクリックします（色を塗る）。
- 国名が分からなければ色が塗られた状態でもう一度クリックします（ポップアップで確認）。
  - これを繰り返すことで覚えていきます。
- 色はポップアップ内の灰色のボタンで元に戻せます。
- 一気に色を塗る、戻す操作は、左上メニューの Regions（地域）パネルから、それぞれの色ボタンをクリックします。
- 小さい国は見つけられないことがあるので、右上の虫眼鏡ボタンから入力欄に地域名を入力し、（出てきたものを展開するのではなく、）地域名部分をクリックすると、未塗り国のどれかにランダムでズームします。

### **地域名入力欄の説明**
- `,` で複数検索できます。
- `;` でコマンド入力できます。
- `.` でコマンドにオプションを指定できます。
- コマンドは`;`で始まり、`;`または`,`で区切られます（明示的に終わらせる必要がある場合も必要です）。
  - 例1（地域名のみ） `asia,africa,oceania`
  - 例2（コマンドのみ） `;cmd1;cmd2;cmd3`
  - 例3（コマンドと地域名の混在） `asia;cmd1,africa;cmd2`
- 次の入力がコマンドの場合は`;`で、地域名の場合は`,`で区切ります。
- 地域名は大文字、小文字の区別はありませんが、コマンドは区別されます。

### **コマンドについて**
- 実行ではなく入力で即時反映なのでコマンドとは言わないかもしれませんが、コマンドと言うことにしてます。
- 今後、コマンドや仕様そのものを変更するかもしれないので、「あれ、使えなくなったな」などがあればここを確認しに来てください。
> [コマンド一覧は下記](#コマンド一覧)

### **コマンド一覧**
#### **ズームボタンを表示**
1. `;zm` 画面の左右両側にズームボタン「+」「-」を表示（zoom の略）
2. `;zm.r` 右のみ表示（right の略）
3. `;zm.l` 左のみ表示（left の略）
4. `;zm.y数値;` ズームボタンのy位置調整（明示的に終わらせる必要があるので終了の`;`または`,`が必要）
5. `;zm.x数値;` ズームボタンのx位置調整（yと同様）
6. `;zm.w数値`  ズームボタンの横幅を指定（widthの略）初期値44(px)
7. `;zm.h数値`  ズームボタンの縦幅を指定（heightの略）初期値44(px)
8. `;zm.s数値`  ズームボタンのサイズを指定（`width`と`height`を同時に指定）
9. `;zm.o数値`  ズームボタンの透明度を指定（opacityの略）
- 例: `;zm.l.y25.s100.o50;` ズームボタンを左のみに表示し、位置を画面下端から25%上、サイズを縦横100px、透明度に50%設定
#### **クロスヘアを表示**
1. `;aim` 画面中央にクロスヘアを表示
2. `;aim.w数値` クロスヘアの横線の長さを指定（widthの略）初期値24(px)
3. `;aim.h数値` クロスヘアの縦線の長さを指定（heightの略）初期値24(px)
4. `;aim.s数値` クロスヘアのサイズを指定（`width`と`height`を同時に指定）
5. `;aim.o数値` クロスヘアの透明度を指定（opacityの略) 初期値100(%)
- 例: `;aim.s20.o30` クロスヘアのサイズを20pxに設定し、透明度を30%に設定
#### **画面位置座標（location）を表示**
1. `;loc` 画面右下に `center: [経度, 緯度], zoom: 数値` を表示
2. `;loc.d数値` 表示する小数桁数を指定（digitsの略）
3. `;loc.s数値` サイズ（font-size）を指定 初期値16(px)
- 例: `;loc.d2.s25` ロケーションを小数第二位まで表示し、font-sizeを25pxに指定
#### **ポップアップ内にピン留めボタンを表示**
1. `;pp` ポップアップ内にピン留めボタンを表示
#### 随時追加していきます。
